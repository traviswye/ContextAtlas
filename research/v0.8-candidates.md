### A1. classifyError catch-all conflates JSON-parse exceptions with API errors

**Originating substep:** v0.4 Step 5 httpx 24-error investigation
(documented in `research/v0.5-candidates.md` #1). Carried forward
through v0.5 + v0.6 + v0.7 cycles.

**Empirical justification:** `classifyError` catch-all logs JSON-
parse failures identically to genuine Anthropic API errors. Root
cause masked during the v0.4 Step 5 investigation; required a
3-sample diagnostic to disambiguate transient API errors from
response-shape errors. User-trust impact: cohort users at v1.0
launch get confusing error messages when extraction fails for
parse-vs-API reasons.

**Fix shape:** Dedicated `ParseError` class + classifier branch
that distinguishes parse failures (deterministic; recheck the LLM
output shape) from API failures (transient; retry with backoff).

**Bounded engineering estimate:** ~30-50 LOC `src/extraction/`
error classification refactor + ~5-10 new tests. Wall-clock ~0.5
cycle days.

**Cohort-impact framing:** User-trust at v0.8+ launch. Cohort
users get substantively distinguishable error messages enabling
self-diagnosis.

**Honest scope-locking disclaimer:** v0.8+ scope-doc drafting
consumption candidate; substantively absorbed per F2-sequencing
adjudication at v0.8+ scope-doc surface.

### A2. extractDocstringsForFile non-idempotent at symbol level

**Originating substep:** v0.4 Step 7 dogfood extraction
(documented in `research/v0.5-candidates.md` #2). Carried forward
through v0.5 + v0.6 + v0.7 cycles.

**Empirical justification:** Re-running extraction on a file with
renamed symbols produces stale-symbol claims that don't get
garbage-collected. Symptom: atlas grows over successive extractions
even on stable corpora. User-trust impact: cohort users at v1.0
launch may see atlas grow unboundedly across re-extractions.

**Fix shape:** Symbol-id-keyed idempotency at extraction time (not
write time). Re-extracted file's claim set replaces the prior claim
set keyed by `(file_path, symbol_id)`.

**Bounded engineering estimate:** ~40-80 LOC `src/extraction/`
idempotency model + ~10-15 new tests. Wall-clock ~1 cycle day.

**Cohort-impact framing:** User-trust + substrate-maintainability
at v0.8+ launch.

**Honest scope-locking disclaimer:** v0.8+ scope-doc drafting
consumption candidate.
